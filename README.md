# ClipCraft

Content repurposing studio with brand memory. Product Space AI Hackathon, Problem Statement 01. Built by voice with Wispr Flow.

Live app: https://theakshai.github.io/productspace-hackathon/

See [features.md](./features.md) for the feature list and build progress.

## Run locally

```bash
npm install
npm run dev
```

Every push to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
